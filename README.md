# 🌌 Mundo Invertido | Stranger Things Landing Page

Uma landing page temática inspirada na série Stranger Things, com alternância entre Mundo Normal (Light Mode) e Mundo Invertido (Dark Mode).

Projeto desenvolvido com foco em prática de HTML, CSS e JavaScript, explorando manipulação de DOM, variáveis CSS, responsividade e efeitos visuais.

---

---

## ✨ Funcionalidades

- 🎭 Alternância entre Light e Dark Mode
- 🌑 Efeito visual de inversão de elementos no tema dark
- 🎵 Áudio automático no carregamento da página
- 🎬 Trailer incorporado via iframe
- 🖼️ Galeria de imagens temática
- 📱 Layout totalmente responsivo
- 📝 Formulário estilizado
- 🎨 Uso de variáveis CSS para gerenciamento de temas

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
- Flexbox
- CSS Variables
- Media Queries

O projeto foi adaptado para:
